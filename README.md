# TieOut Canvas desktop app

Installers and update files for the TieOut Canvas desktop app for Windows, from [RevRec Canvas](https://www.revreccanvas.com/tieout.html).

Download the latest installer from **[Releases](https://github.com/beavon2010/tieout-canvas-releases/releases/latest)**. The app installs for your Windows user only (no administrator rights needed) and updates itself after that.

This repository holds release files only. Every update is signed; the app refuses any update whose signature doesn't match.
